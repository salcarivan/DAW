# Sonidos Metal

## Overview

Sonidos Metal is a dedicated website showcasing five iconic metal artists. The site provides information about each artist, including their biography, discography, and audio samples of their music. 

## Artists Featured

1. **Iron Maiden**
2. **Rammstein**
3. **Judas Priest**
4. **Motörhead**
5. **Mägo de Oz**

## Project Structure

```
sonidos-metal
├── index.html          # Main entry point of the website
├── iron-maiden.html    # Information about Iron Maiden
├── rammstein.html      # Information about Rammstein
├── judas-priest.html   # Information about Judas Priest
├── motorhead.html      # Information about Motörhead
├── mago-de-oz.html     # Information about Mägo de Oz
├── css
│   └── styles.css      # Styles for the website
├── js
│   └── script.js       # JavaScript functionality
├── imagenes            # Directory for artist images
└── sonidos             # Directory for audio files
```

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the site.
3. Ensure that the `imagenes` and `sonidos` directories contain the appropriate files for images and audio.

## Additional Information

- The website is designed to be responsive and user-friendly.
- Each artist page includes sections for presentation, biography, discography, and audio playback.
- The project adheres to HTML5 standards and best practices for web development.
